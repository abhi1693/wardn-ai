= Local Development
:revdate: 2026-08-09
:page-revdate: {revdate}
:description: Common local development commands for the Wardn backend, frontend, workers, OpenAPI generation, and docs.

[#_backend]
== Backend

[source,bash]
----
npm run backend:lint
npm run backend:test
npm run backend:typecheck
----

Run the API:

[source,bash]
----
cd wardn/backend
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
----

Run migrations:

[source,bash]
----
cd wardn/backend
uv run alembic upgrade head
----

[#_frontend]
== Frontend

[source,bash]
----
npm run web:dev
npm run web:lint
npm run web:build
----

[#_openapi_client]
== OpenAPI client

Regenerate the FastAPI OpenAPI schema and the Orval client when backend request or response schemas change:

[source,bash]
----
npm run web:api:generate
----

Refresh the docs copy of the OpenAPI artifact:

[source,bash]
----
npm run docs:sync:openapi
----

[#_docs]
== Docs

Install docs dependencies:

[source,bash]
----
cd docs
npm ci
----

Build the docs site:

[source,bash]
----
npm run docs:build
----

Preview the built static site:

[source,bash]
----
npm run docs:preview
----
