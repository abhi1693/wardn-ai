= Install an MCP Server
:revdate: 2026-08-09
:page-revdate: {revdate}
:description: Install an approved MCP server into a Wardn workspace and validate its tools.

An MCP server must be represented in the organization catalog before it can be installed into a workspace.

[#_catalog_first]
== Add or sync catalog metadata

. Open the organization catalog.
. Add a server manually or sync metadata from a trusted source.
. Review the server metadata and version.
. Set the intended default version if multiple versions exist.

[#_install_to_workspace]
== Install into a workspace

. Open the workspace MCP registry.
. Select the server and version.
. Provide configuration values required by the server.
. Bind any required secret handles.
. Start the installation job.
. Monitor the job status until it succeeds or fails.

[#_validate_tools]
== Validate tools

Endpoint validation proves that the server initializes and exposes tools.

Tool validation proves that the configured credentials can run a specific tool with specific arguments.

Run representative tool validation before binding the server to agents.
